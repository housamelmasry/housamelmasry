## 👨‍💻 About Me

> Backend Engineer with **4+ years of hands-on experience** building business systems, REST APIs, and multi-platform applications.

My primary backend experience is with **Laravel/PHP**, and I'm currently expanding deeply into **TypeScript, Node.js, and NestJS**, with a focus on backend architecture, scalable APIs, multi-tenancy, asynchronous workflows, and real-time systems.

I've built and maintained complete systems independently — from database design and backend architecture to APIs, admin panels, mobile applications, integrations, and deployment workflows.

### What I Build

* 🏗️ **Backend systems** with Laravel, NestJS, REST APIs, authentication, RBAC, and modular architecture
* 🚚 **Multi-tenant SaaS platforms** with PostgreSQL, Prisma, Redis, queues, webhooks, and real-time tracking
* ⚡ **Asynchronous workflows** using queues, retries, event-driven processing, and external integrations
* 📱 **Cross-platform mobile applications** with React Native CLI and custom native modules in Swift & Kotlin
* 🔐 **Business-critical workflows** involving authentication, authorization, state machines, OTP, rate limiting, and data protection
* 🧩 **Domain-driven systems** such as logistics, ERP/CRM, POS, inventory, and educational applications

### Previous Experience

* 🏢 **Laravel/PHP** — ERP/CRM systems, multi-branch POS, inventory, billing, RBAC, and REST APIs
* 📱 **React Native CLI** — production mobile applications with custom iOS and Android native modules
* 📖 **Quran technology** — Arabic Mushaf rendering, Quranic data APIs, speech recognition, and on-device audio analysis
